## Top issues by severity

### Security
1. **Excluded-tool refusal can be bypassed by newline smuggling** (FDR 0002 #13/#29, E2). Request bodies reach child stdin unchanged (`mcphttp/server.go:287,388` → `translator.go:183-187`). A valid multi-line JSON body with method `ping` can carry a complete excluded `tools/call` on its own line, and any newline-framed stdio child will execute it. This breaks the FDR's own "single line" claim (0002:169-170). **Fix:** compact the body (`json.Compact`) or reject bodies containing a raw `\n` in `handlePost` before forwarding. Add a regression test.
2. **Excluded-tool refusal can be bypassed by key case** (E2). `refuseExcludedCall` matches keys exactly (`http.go:281-286`), while case-insensitive decoders (Go `encoding/json` structs, the spine's own probe at `server.go:259-263`, and the test's fake child at `exclude_tools_test.go:187-196`) take the last case-variant key. `{"name":"kept","Name":"excluded"}` gets through. **Fix:** fail closed when any case-variant of `method`, `params` or `name` names an excluded tool or differs from the exact key.
3. **ADR 0006's invariant is broken under `--agent-scope` and the ADR was not reopened** (A3, E3). In-unit, the bridge's port is in the worker's manifest and on the worker's loopback, so the unauthenticated `/clown/exclude-tools` lets the worker clear its own exclusions. FDR 0020:597-604 already says this exclusion is "policy, not a boundary", but ADR 0006 and FDR 0002 do not. **Fix:** reopen ADR 0006 with an agent-scope note. If exclusion must ever be a boundary, authenticate `/clown/*` with a token passed over the handshake channel, or enforce in the frontend.

### Correctness
4. **A child line over 1 MiB kills the reader silently** (#24). The bridge stays up and healthy while every later request hangs. **Fix:** make a reader error fatal (exit non-zero, or `/healthz` 503).
5. **Outbound drops are neither logged nor counted externally** (#22). `DroppedOutbound()` has no caller. **Fix:** log the drop and emit a statsd counter.
6. **Bare PATH commands are rewritten to `<pluginDir>/<cmd>`** (#4). This contradicts the FDR's own example. **Fix:** absolutize only commands that contain `/`, or change the doc and example.
7. **Concurrent sessions with overlapping ids are rejected** (#30). **Fix:** remap ids, or document single-session support.
8. **FDR 0004 `--settings` merge rule conflicts with existing precedence** (0004 #5, `claude.go:31-32`). Resolve before building.

### Doc-only
9. FDR 0002: `/healthz` semantics (#15), the "no MCP semantics" claim (#17), trust-boundary location under agent scope (#25), whole-block `mcpServers` replacement (#28), the undocumented `CLOWN_BRIDGE_SERVER_NAME` (#5).
10. FDR 0004: nothing is implemented. The doc should say so explicitly, and its stale line references (#14) should be fixed.
11. Untested MET claims: stderr forwarding (#10), SIGTERM handling (#16), child-crash exit (#19), inbound queue-full `-32000` (#21).
