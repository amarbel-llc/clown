## Top issues by severity

**Security**
1. **Row 83.** The operator's real `~/.claude/.credentials.json` is bound **read-write** into the unit (as.go:350-357). A confined agent can read the operator's OAuth credential, replace it, or send it to an allowlisted host. The FDR leaves this as an "open question". Close it: bind it read-only, or use a per-session credential.
2. **Row 6.** Fail-closed covers only a `systemd-run` error. After start, clown verifies only the pid namespace (run.go:137-140). Nothing in the launch path confirms the net, mount and user namespaces before the result is written; only the host-only bats lane does. Add an ns-inode comparison in `waitActive`.

**Correctness**
3. **Row 9.** claude is pid 1 inside the unit (the shim execs it), so orphans are never reaped. nikulin round P: zombies went from 2 to 6 in one session. Make `agent-exec` a reaping init that fork/execs claude.
4. **Row 33.** ssh git has no `known_hosts`, and strict checking stays on. The only test passes because it disables checking itself (bats:285). Real ssh fetch and push from a confined worker are unverified and likely fail on host-key verification.
5. **Row 28.** The default egress allowlist omits the krone nix cache that the FDR promises, and adds about 8 hosts the FDR does not list.
6. **Rows 42, 43, 68.** The `CLOWN_DISABLE_STATSD` pass-through, the statsd-relay failure path and in-unit SIGWINCH and resize have no tests.

**Doc-only (the FDR is wrong about the code)**
7. **Rows 54, 59, 79, 81.** The XDG story contradicts itself (line 209 against line 219) and the code. STATE, LOG and DATA are the operator's paths with clown-bound real subdirs (hook-toolcost, hook-tee, moxy logs). CONFIG and CACHE default under the agent home.
8. **Rows 74, 76, 73.** The MCP wiring is described wrongly. There is no `mcp-socket-relay` and no per-connection stdio server: frontend servers are reached through PortForward to their loopback HTTP port. In-unit servers are children of `agent-relay`, not claude's stdio children. Loopback TCP *is* offered for the forwarded services.
9. **Row 72.** The idle socket is exempt from the peer-cred rule, by design; the FDR should say so.
10. **Rows 26, 49, 11, 5.** Proxy env details (`ALL_PROXY`, `::1`, CONNECT-only), the review of the `CLAUDE_CODE_` prefix for secrets, the stale PrivateNetwork status, and the piggy refusal claim, which is piggy-side and not tested by clown.
