## Top issues by severity

**Security**
1. **#43/#73, egress proxy reaches host loopback.** The proxy appends ANTHROPIC_BASE_URL's host:port to the allowlist (cmd/clown/agentscope.go:175-177), and EgressProxy has no loopback refusal (internal/agentscope/egress.go:131-137). With a local juggler, any in-unit process can CONNECT to that host-loopback port. This contradicts FDR 538-540 and 668. Fix: drop loopback hosts from the appended entry, and refuse loopback/link-local targets in the proxy.
2. **#60, recipe scoping is unenforced** (acknowledged; moxy#487). This is live: nikulin J3 ran run_recipe.

**Correctness**
3. **#10, the result file is not reliable on failure.** A launch that fails after LoadSpec but before Run writes no result (agentscope.go:35-49). A unit that goes active and then fails, e.g. the in-unit exclusion refusal, which exits 126, leaves a success result (run.go:165-186). A unit that exits before it settles can leave none (run.go:199-203). spinclass keys off this file.
4. **#58, the bridge's excluded-call refusal can be bypassed** with case-variant `Method`/`Params` keys, which the Go spine and a Go child accept (cmd/clown-stdio-bridge/http.go:283-286 vs internal/mcphttp/server.go:259-263). The FDR calls this policy, but these exclusions exist to hide spinclass spawn/merge tools.
5. **#78, no reaping init.** Zombies accumulate (nikulin P).
6. **#27/#65, frontend monitors are unverified in a real unit.** No host test reads a monitor socket from inside a unit, and no live round has run. **#34**: Pdeathsig is untested and reaches only `sh -c`.
7. **#3, no explicit darwin refusal.** internal/agentscope also uses Linux-only x/sys/unix symbols without build tags, so a darwin build may break.
8. Side finding (#30): a partial replay re-sends lines that were already delivered (duplicate wakes).
