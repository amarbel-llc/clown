### Restart gap found live (2026-10-26 15:50): PRIORITY 1, not built

- **V** First live `restart-child-session` (circus/solid-elm throwaway,
  unconfined): clown's close-self-run.log for that principal shows idle
  pokes at 15:28:13, 15:39:40 and 15:40:59, then none until the frontend
  exited at 15:46:03 with "restart queued and never asked about"
  (`noteExit`, `cmd/clown/restart_idle.go`). `restart-preflight` was never
  called, so spinclass's `restarting_at` and `restarted_at` stayed null and
  no start/back wake or watchdog armed.
- **R** Cause: `clown restart --when idle` only queues in memory
  (`restartControlHandlerNow`, `cmd/clown/restart.go`: `q.put` then OK). The
  preflight runs only on a Stop datagram (`idleRunner.onIdle`). A session
  that was already idle when the request arrived gets no further Stop until
  someone prompts it. Spinclass's queue message says "once its current turn
  ends", which is false for an idle session. This is the opposite of the
  "hung session" case on the restart page (a busy session that never
  reaches Stop); the page and clown-restart(1) ("at the next idle
  transition") do not mention it.
- **I** The relaunch was not clown's restart path (`noteExit` only logs when
  no restart is underway). The exit coincides with the fleet restart, so it
  was probably relaunched through spinclass's resume entry. The queue lived
  only in the dead frontend's memory. Spinclass clears `RestartRequest` in
  four places (`restart_cmd.go`: hand-off failure ~175, preflight refusal
  ~475, consume ~509, cancel ~756); only the hand-off failure/timeout or a
  cancel fit, and spinclass's servelog says which.
- **Fix (smallest, ~2-3 h, independent review):** when the control handler
  queues an `idle` request and the frontend is currently idle (the busy flag
  in `cmd/clown/selfclose.go` is false, which is also true right after
  launch), run the idle path once at once in the background (`onIdle`:
  close-self-run, then the preflight). A busy session still waits for its
  Stop. The 30 s countdown and the busy-cancel rule are unchanged, and
  nothing restarts without spinclass's "restart" verdict. Tests with a real
  listener: idle frontend + request => exactly one preflight with no
  datagram; busy frontend + request => none until the Stop datagram; busy
  flips during the countdown => cancelled as today; a request racing a poke
  => one preflight. Update clown-restart(1), the restart page and FDR 0020.
- **Workaround until it ships:** any message that makes the child run a
  turn, so its Stop fires the preflight.
