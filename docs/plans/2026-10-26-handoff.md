  debug-test-go-godyn-failures`) before every fix, then green.

  findings were folded in as follow-up commits that reference the issue.

  lint-juggler-boundary` when juggler files change; `just lint-man` when
  man pages change; then `just test-go-godyn`. Use the race lane (`just
  debug-test-go-race-failures`, then `just test-go-race`) for concurrency
  work.
- One gate or nix run at a time. Check resources before each run (memory
  available above 6 GB, load1 below 15, root disk free above 20 GB), and use
  `just debug-wait-for-resources` while a merge gate is running.
- Pre-existing bugs found mid-task are filed as issues with file:line, not
  fixed in the batch. A production gap found while fixing tests is stopped
  and reported (as with #317), not hidden behind a longer timeout.
